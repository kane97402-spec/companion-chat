About companion.

A personal character-chat interface.

This version is a front-end prototype. It includes character selection, separate chat histories, six chat modes, browser voice input, and optional read-aloud.

Important: The replies are demo responses, not a connected AI model. Conversations are stored only in this browser using local storage; they are not synced across devices.

Real AI conversations, secure account-based memory, and animated 2D characters require additional services and are not active in this version.
