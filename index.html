About companion.

What works in this version

This is the first redesigned front-end: character portraits, character switching, separate conversations, local chat history, six modes, and browser voice features.

Important: The chat currently uses demonstration replies, not a connected AI model. Real character personalities, cloud memory, and reliable voice conversations require a secure AI backend. An API secret must never be placed in this public website's code.

Portraits are requested from the public Jikan anime database. If a portrait fails to load, the app shows a fallback image.
